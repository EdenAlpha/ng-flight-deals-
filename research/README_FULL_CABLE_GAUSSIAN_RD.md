# Full-cable Gaussian RD map

Model-based diagnostic only. This branch extends PR #368 from four representative regions to all 54 fixed 128-channel Imperial Valley blocks. It does not claim a rate lower bound for the real non-Gaussian file and does not change the compression benchmark. Each block uses the unchanged global 10%-std epsilon, matched SZ3, all 30,000 samples for byte accounting, and all 29 complete 1024-sample windows for the stationary 2-D covariance-spectrum estimate.
